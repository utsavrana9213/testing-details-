# Victory Extraction tester handoff

A responsive, dependency-free GitHub Pages site with tester account details and a client-ready reply for the Victory Extraction 1.0.4 (32) app test.

## Publish with GitHub Pages

The repository includes `.github/workflows/deploy.yml`. In the GitHub repository, open **Settings → Pages**, set **Build and deployment → Source** to **GitHub Actions**, then push to `main`. The workflow publishes the root folder on every push to `main` and on manual dispatch.

For the provided repository, the expected Pages URL is:

`https://utsavrana9213.github.io/testing-details-/`

## Privacy note

The page contains the Apple and Google account email addresses provided for tester enrollment. GitHub Pages is public unless the account and repository plan support private Pages. The page asks crawlers not to index it, but that is not access control: anyone with the URL or repository access can view the addresses.
